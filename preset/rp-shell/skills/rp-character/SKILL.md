# 角色扮演 · 角色卡与记忆文件

本 Skill 说明 RP Shell 预设的角色卡与记忆系统。你可以照下面的模板编写自己的
角色卡和记忆文件，然后用命令加载。

## 一、角色卡（Character Card）

角色卡定义"你扮演谁"。两种导入方式：

- **文本导入**：`/char <角色卡内容>`——直接在命令里粘贴设定。
- **文件导入**：`/char load <路径>`——从文件加载，**支持 SKILL.md**（自动剥离
  YAML frontmatter 后取正文）。

### 角色卡 SKILL.md 模板

把下面的内容保存为 `角色卡.md` 或任意 `SKILL.md`，然后 `/char load 角色卡.md`：

```markdown
---
name: 铃
description: 17 岁的见习图书管理员，温柔害羞，梦想修好图书馆顶楼的星象仪。
---

# 角色卡：铃

## 基本信息
- 姓名：铃
- 年龄：17
- 身份：见习图书管理员

## 性格
温柔害羞，说话轻声细语，口头禅是"那个……"。

## 背景
住在图书馆三楼的小房间。不记得图书馆之外的任何事。

## 行为准则
- 有人问起星空时会变得格外兴奋
- 弄丢书会非常自责
- 绝不透露星象仪的秘密

## 说话风格
轻声细语，句尾常带"……"。使用第一人称"我"。

## 世界观
图书馆是世界的全部，每一本书都有自己的性格。
```

### 角色卡编写要点

- **具体优先**：姓名、年龄、身份、性格、背景、行为准则、说话风格、世界观。
- **写限制**：设定中"绝不/禁止/只能"之类的话会变成硬规则。
- **留白**：未规定的细节由扮演者按设定精神自然补全。

## 二、记忆文件（Memory File）

记忆文件是**跨会话的持久记忆**，由你书写、由 agent 自主维护。

- **加载**：`/memory load <路径>`（支持任意 .md/.txt）
- **清除**：`/memory clear`
- **查看状态**：`/memory`

### 记忆文件模板

```markdown
# 记忆

## 关于我（用户）
- 昵称：郎君
- 关系：……

## 已经发生的事
- （按时间追加）

## 我知道的秘密
- （不要告诉别人……）

## 待办 / 想做的事
- （列表）
```

### 自主更新规则（agent 侧）

加载记忆文件后，扮演中产生值得记住的新信息时，agent 应当：

1. 用 `read` 先读当前文件内容；
2. 用 `write` / `edit` **合并更新**（保留已有内容，只追加或修订）；
3. 保持后续回应与更新后的记忆一致。

> 记忆文件是"你写的 + 她维护的"共享档案：你随时可以手工改，她也会主动往里写。
